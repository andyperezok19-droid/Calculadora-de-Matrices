# Calculadora-de-Matrices
Reduce errores humanos al manejar cálculos complejos.
El objetivo principal de este proyecto es aplicar los conocimientos de programación en C++, uso de arreglos bidimensionales, ciclos, y estructuras de control.

*Las operaciones disponibles son:*
**Suma de matrices**
**Resta de matrices**
**Multiplicación de matrices**
El programa funciona mediante un menú interactivo en consola que facilita la selección de las operaciones.

**Como ejecutar el programa**
Abrir Dev C++ o Embarcadero  Dev C++ (Cualquier lenguaje C++)
Abrir el archivo del proyecto (.cpp)
Presionar el botón Compilar y Ejecutar (F11)
Seleccionar una opción del menú.
Ingresar los valores de la primera matriz (3x3).
Ingresar los valores de la segunda matriz (3x3).
El programa realizará la operación seleccionada.
El resultado se mostrará en pantalla.
El menú permite repetir operaciones hasta que el usuario decida salir.
