# Calculadora-de-Matrices<br>
Reduce errores humanos al manejar cálculos complejos.<br>
El objetivo principal de este proyecto es aplicar los conocimientos de programación en C++, uso de arreglos bidimensionales, ciclos, y estructuras de control.<p>

**Las operaciones disponibles son:** <br>
**Suma de matrices** <br>
**Resta de matrices**<br>
**Multiplicación de matrices**<br>
El programa funciona mediante un menú interactivo en consola que facilita la selección de las operaciones.<p>

**Como ejecutar el programa** <br>
Abrir Dev C++ o Embarcadero  Dev C++ (Cualquier lenguaje C++)<br>
Abrir el archivo del proyecto (.cpp)<br>
Presionar el botón Compilar y Ejecutar (F11)<br>
Seleccionar una opción del menú.<br>
Ingresar los valores de la primera matriz (3x3).<br>
Ingresar los valores de la segunda matriz (3x3).<br>
El programa realizará la operación seleccionada.<br>
El resultado se mostrará en pantalla.<br>
El menú permite repetir operaciones hasta que el usuario decida salir.<p>
