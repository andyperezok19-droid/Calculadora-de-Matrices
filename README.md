# Calculadora-de-Matrices<p>
Reduce errores humanos al manejar cálculos complejos.<p>
El objetivo principal de este proyecto es aplicar los conocimientos de programación en C++, uso de arreglos bidimensionales, ciclos, y estructuras de control.<p>

*Las operaciones disponibles son:*<p>
**Suma de matrices**<p>
**Resta de matrices**<p>
**Multiplicación de matrices**<p>
El programa funciona mediante un menú interactivo en consola que facilita la selección de las operaciones.<p>

**Como ejecutar el programa**<p>
Abrir Dev C++ o Embarcadero  Dev C++ (Cualquier lenguaje C++)<p>
Abrir el archivo del proyecto (.cpp)<p>
Presionar el botón Compilar y Ejecutar (F11)<p>
Seleccionar una opción del menú.<p>
Ingresar los valores de la primera matriz (3x3).<p>
Ingresar los valores de la segunda matriz (3x3).<p>
El programa realizará la operación seleccionada.<p>
El resultado se mostrará en pantalla.<p>
El menú permite repetir operaciones hasta que el usuario decida salir.<p>
